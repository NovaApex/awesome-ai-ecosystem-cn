# GitHub 项目简介索引

把平时收集、调研过的 GitHub 项目，按统一格式整理成一份**零基础友好**的静态网页索引。

## 这是什么

- 核心文件只有一个：`github.html`（纯静态、无依赖、离线可用，浏览器双击即开）
- 每个项目一条折叠块，包含：**仓库链接 / 定位 / 能力特性 / 用法示例 / 要点**
- 顶部目录按五类分组（带组内计数）：
  🛠️ AI 开发工具与运行环境 · 🧰 领域专用工具 · 🧩 Agent 技能、插件与组件 · 🌐 平台与框架 · 📚 学习资料与方法论
- 内置全文搜索框：输入关键词即时过滤（匹配项目名 / 仓库名 / 简介 / 技术词）
- 点击目录项自动展开对应折叠块并闪烁高亮，页内跳转

## 怎么用

1. 下载本仓库中的 `github.html`
2. 用任意现代浏览器打开即可（无需服务器、无需联网）
3. 顶部搜索框可当"工具速查表"用：想找某类工具（如 docker、MCP、TypeScript）直接搜

> 注：GitHub 网页上直接查看 `github.html` 会显示源码而非渲染效果，请下载后本地打开。

## 维护约定

- 条目格式统一：折叠块 `<details>`（含唯一 slug `id` + `data-cat/data-name/data-repo/data-blurb` 四属性）+ 摘要行（名称 / 仓库 / 一句话）+ 正文四段（定位 / 能力 / 用法 / 要点）
- 所有命令、路径、版本号等事实**只来自 README 原文与官方 API**，不采用第三方转述；数字类信息必须标注取数日期
- 新增/删除条目后同步更新：对应分类 `<h2>` 的计数、顶部说明里的总数

## manage-skill：自动化维护技能

本仓库的日常维护由一个项目级 AI 技能托管：[`skills/manage-skill/`](skills/manage-skill/)。在 WorkBuddy 中打开本仓库所在工作区即可自动识别、按指令触发。

### 目录结构

```
skills/manage-skill/
├── SKILL.md            # 技能主文件：触发条件、操作步骤、统一格式规范
├── references/
│   └── gate.md         # 运行结果审查标准（质量门）
├── scripts/            # 脚本/代码库（预留）
└── assets/             # 素材库（预留）
```

### 功能 1：GitHub 项目记录

- **触发**：对 AI 说"记录一下这个项目"或直接贴出 GitHub 仓库地址
- **流程**：① 在 `github.html` 中查重（已收录则告知所在分类）→ ② 访问仓库读取 README / License / Star 等原文信息 → ③ 按「统一格式规范」生成折叠块条目，判断所属分类并更新计数

### 功能 2：内容质量审查

- **触发**：`github.html` 内容发生改变之后自动启动
- **流程**：读取 `references/gate.md` 审查标准 → 对变更内容逐项审查，输出「通过 / 问题清单」

### gate.md 审查三大重点

1. **可读性**：一句话钩子 ≤ 40 字、专业术语首次出现给零基础解释、单条 4–10 个要点约 150–600 字
2. **内容质量**：定位 / 能力 / 用法 / 要点四段覆盖；事实来自原文不编造；Star 等数据带取数日期；仓库异常（停更、转载等）如实标注不得美化
3. **HTML 结构**：slug 唯一、四 data 属性齐全、分类正确、计数同步、公共部分（样式/脚本）不得改动等 8 项硬性检查
